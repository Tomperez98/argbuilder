# `git`

**Usage:** `git [OPTIONS] [COMMAND]`

**Commands:**

* `add` — Adds things [aliases: stage]
* `rm`
* `help` — Print this message or the help of the given subcommand(s)

**Options:**

* `-v...` — Be loud
* `--color <COLOR>` — [aliases: --colour]
* `-h, --help` — Print help

## `git add`

Adds things

**Usage:** `git add [OPTIONS]`

**Options:**

* `-f` — [short aliases: -F]
* `-v...` — Be loud
* `-h, --help` — Print help

## `git rm`

**Usage:** `git rm [OPTIONS]`

**Options:**

* `-v...` — Be loud
* `-h, --help` — Print help

## `git help`

Print this message or the help of the given subcommand(s)

**Usage:** `git help [COMMAND]...`

**Arguments:**

* `[COMMAND]...`
